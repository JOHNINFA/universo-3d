# Universo de Mundos
Mundo 3D en el navegador (three.js) con personajes estilo avatar Xbox, planetas, valle con 12 habitantes, necesidades, rutinas, memoria, conversación, milagros del Creador, ciclo día/noche, familias y guardado.
Un solo archivo HTML, sin build. Three.js desde CDN con versión fija (0.187.0).
Correr: `python3 -m http.server 8777 --bind 127.0.0.1` y abrir http://localhost:8777 (puerto 8765 lo usa Lira/Odín).
En esta PC el 3D va por software: usar el lanzador "Chrome (WebGL) — WareTrack"; si WebGL falla, la página avisa con qué hacer.
