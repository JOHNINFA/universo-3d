# Universo de Mundos
Mundo 3D en el navegador (three.js) con personajes estilo avatar Xbox, Tierra, Luna y planeta con anillo.
Correr: `npm install && python3 -m http.server 8777 --bind 127.0.0.1` y abrir http://localhost:8777
(Ojo: el puerto 8765 lo usa Lira y Odín.) En esta PC Chrome necesita WebGL por software (ver lecciones).
Archivos: main.js (escena y cámara), avatar.js (personajes), space.js (cielo y planetas).
